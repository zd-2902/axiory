# Produkt

Axiory unterstützt B2B-Analysten beim nachvollziehbaren Vergleich von
Versicherungsprodukten. Der MVP fokussiert Schweizer Reiseversicherungen und deren
öffentlich zugängliche AVB/Produktinformationen. Langfristig folgen weitere Sparten
und strategische Wettbewerbsanalysen.

Zielablauf: Dokument erfassen → Leistungen, Ausschlüsse, Limiten und Bedingungen
extrahieren → auf Ontologie normalisieren → Originalfundstellen prüfen → vergleichbar
anzeigen. Nutzer sollen jede Aussage bis zur konkreten Dokumentversion zurückverfolgen.

Das Fundament demonstriert diesen Datenvertrag mit zwei vollständig erfundenen
Produkten. Die vorläufige Ontologie umfasst Annullierung, medizinische Leistungen
und Gepäck. Fachliche Produktbewertungen, Rankings, Beratung, Schadenabwicklung
und automatisierte Kaufempfehlungen liegen ausserhalb dieses Schritts.

Erfolg bedeutet zuerst korrekte, belegte Aussagen und sichtbare Wissenslücken.
Eine nicht gefundene Leistung ist unbekannt; ein Ausschluss braucht eine explizite
Fundstelle. Einschränkungen sind Bestandteil einer Leistung, keine Fussnote.
