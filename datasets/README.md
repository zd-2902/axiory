# Datenregeln

Aktuell ausschliesslich synthetische Fixtures, definiert in `src/axiory/demo.py`.
`uv run axiory-demo` gibt Quelltexte und strukturierte Datensätze gemeinsam aus.
Keine echten Versicherungsunterlagen, personenbezogenen Daten oder Zugangsdaten ablegen.
Die späteren Ordner `raw/` und `processed/` sind vorsorglich von Git ausgeschlossen.
Die Freigabe echter Daten setzt das Gate in `docs/ROADMAP.md` voraus.
